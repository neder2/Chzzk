# 업데이트 내역

## 1.2.1 (2026-07-05)

### 탐색 및 옵션 화면

- 팔로잉 호버 미리보기의 `pstatic.net` HLS 권한을 설치 시 필수 권한에서 선택 권한으로 옮겼습니다. 옵션에서 팔로잉 미리보기를 켤 때만 권한을 요청하고, 거부되면 토글을 다시 끕니다.
- 선택 권한 흐름에 맞춰 팔로잉 호버 미리보기 기본값을 꺼짐으로 바꾸고, README의 기본값과 권한 설명을 함께 갱신했습니다.
- 라이브 시청 기록 화면의 검색/정렬/삭제 컨트롤, 요약 카드, 선택 행, 세션 행 스타일을 좁은 폭에서도 덜 넘치도록 정리했습니다.

### 수정 및 안정화

- 치지직이 매니저 칭호를 "채팅 운영자"로 바꾼 것에 맞춰 모아보기 패널·옵션·문서의 표기를 갱신했습니다. 감지는 기존에도 두 명칭을 모두 인식했으며, 새 칭호 마크업에 대한 회귀 테스트를 추가했습니다.
- 팔로잉 호버 미리보기가 실시간보다 20~30초 뒤처진 위치부터 재생되던 문제를 고쳤습니다. 미디어 목록에 저지연(LLHLS) 스트림이 있으면 우선 사용하고, 없으면 기존 HLS로 폴백합니다.
- 라이브 채팅 영역이 통째로 재생성되는 경우(채팅 접기/펼치기, 플레이어 모드 전환 등) 방송자/채팅 운영자 모아보기 버튼이 사라진 채 돌아오지 않던 문제를 고쳤습니다. 감시하던 채팅 노드가 교체되면 새 노드를 다시 찾아 감시를 이어갑니다.
- 채팅 도구의 블라인드 원문 표시는 확인 가능한 원문이 있을 때만 기존 블라인드 문구 자리에 취소선으로 되살리도록 바꿨습니다. 원문을 모르는 블라인드 문구는 임의 대체 문구를 만들지 않고 그대로 둡니다.
- 방송자/채팅 운영자 모아보기는 실제 치지직 채팅 마크업의 뱃지 이미지와 닉네임 색상을 보존하고, 닉네임 클릭 프로필 카드나 화면에 보이지 않는 보조 설명 텍스트를 메시지로 오인하지 않도록 보강했습니다.
- 방송자/채팅 운영자 모아보기 캐시는 같은 라이브 세션에서만 복원되도록 `liveId` 기준을 추가하고, 새 방송에서는 이전 방송의 수집분을 버리도록 정리했습니다.
- 단축키 복구가 플레이어 밖 버튼/링크 입력에는 개입하지 않도록 하는 판정을 공용 유틸로 옮겨 플레이어 관련 기능들이 같은 기준을 쓰도록 했습니다.
- 오디오 컴프레서 버튼은 플레이어 컨트롤이 늦게 class/style 변화로 로드되는 경우에도 다시 감지하며, 버튼 자신이 만든 attribute 변경으로 재동기화 루프가 생기지 않도록 막았습니다.
- 월간 방송 달력은 다크 모드에서 방송일 배경과 내 시청 표시 점이 겹쳐도 점이 묻히지 않도록 색상을 조정했습니다.

### 문서

- README의 팔로잉 미리보기 권한/기본값 설명을 1.2.1 동작에 맞췄습니다.

## 1.2.0 (2026-07-04)

### 새 기능

- `통나무 보상 자동 받기` 옵션을 추가했습니다. 기본값은 켜짐이며, 시청 시간 조작이나 보상 API 직접 호출 없이 치지직 페이지가 실제로 표시한 통나무 보상 버튼만 한 번 클릭합니다.
- `채팅 도구` 옵션을 추가했습니다. 기본값은 꺼짐이며, 확인할 수 있는 블라인드 채팅 원문만 보여 주고 방송자/매니저 채팅을 채팅창 우측 상단 아이콘에서 여는 패널에 모아 보여 줍니다. `방송 중 모아보기 유지`를 켜면 보고 있는 동안 모은 방송자/매니저 채팅만 같은 방송 재입장 때 다시 보여 줍니다.
- `오디오 컴프레서` 옵션을 추가했습니다. 기본값은 꺼짐이며, 옵션을 켜면 라이브/다시보기 볼륨 컨트롤에 치즈나이프식 컴프레서 버튼을 표시하고 옵션을 끄면 버튼을 제거합니다. 치즈나이프 컴프레서가 감지되면 오디오 소스 충돌을 피하기 위해 Better Chzzk 컴프레서 버튼을 자동으로 숨기고, 치즈나이프가 없으면 기존대로 동작합니다.
- `팔로잉 미리보기 소리` 옵션을 추가했습니다. 기본값은 켜짐이며, 주 플레이어 볼륨으로 미리보기 소리 재생을 시도하고 브라우저가 소리 자동재생을 막으면 카드 안 버튼으로 소리를 켤 수 있습니다.

### 탐색 및 옵션 화면

- 옵션 화면에 통나무 보상, 오디오 컴프레서, 채팅 도구, 팔로잉 미리보기 소리 설정을 추가하고 상위 토글 상태에 따라 세부 입력이 함께 비활성화되도록 정리했습니다.
- 채팅 도구 설정을 별도 섹션으로 분리하고, 방송자/매니저 모아보기 캐시와 보관 개수 설정을 한곳에서 조절할 수 있게 했습니다.
- 전체 방송/카테고리 목록 도구는 검색, 필터, 팔로워 수 배지, 진행 시간 배지를 큰 목록에서도 덜 무겁게 갱신하도록 화면 근처 카드와 주기적 동기화 중심으로 정리했습니다.
- 팔로잉 미리보기 카드는 라이브 썸네일을 우선 사용하고, 썸네일이 없을 때 `LIVE` 같은 장식용 대체 화면을 만들지 않도록 정리했습니다.

### 수정 및 안정화

- 팔로잉 미리보기는 기존 MAIN world 영상 브리지를 제거하고, 전체 방송 탐색 hover와 같은 `auto-play-info` HLS 정보를 받아 카드 안에서 재생하도록 다시 만들었습니다. 기본적으로 주 플레이어 볼륨으로 소리 재생을 시도하고, 브라우저가 자동재생을 막으면 음소거로 전환한 뒤 카드 안 버튼으로 소리를 켤 수 있습니다.
- 팔로잉 미리보기에서 CHZZK `player-vendor` 원격 import, 새 창, 새 탭, 팝업, iframe, 라이브 페이지 삽입 fallback을 사용하지 않도록 정리했습니다.
- 팔로잉 미리보기 카드 자체는 즉시 열되, 메타데이터 조회와 플레이어 시작은 짧게 지연해 지나가는 호버에서 불필요한 요청이 생기는 일을 줄였습니다.
- 팔로잉 미리보기 플레이어를 메인 라이브 플레이어로 오인하지 않도록 공용 비디오 선택 로직을 보강했습니다.
- 자동 화질 복구가 다시보기 진입 직후의 안정된 상태를 더 정확히 판단하고, 이미 원하는 화질이 적용된 경우 불필요한 재적용과 리스너를 정리하도록 개선했습니다.
- 라이브 위치 유지가 시크바 드래그, 명시적인 라이브 끝 이동, 일시정지 후 이어보기, 비디오 교체 상황을 더 구분해 사용자가 의도한 위치를 되돌리지 않도록 보강했습니다.
- 17시간 단위로 분할된 다시보기에서 방송 시각 표시가 원본 방송 시작 기준으로 앞당겨지던 문제를 보정했습니다.
- 월간 방송 달력은 KST 날짜 경계를 기준으로 방송일을 칠하고, 같은 날짜에 방송 시간과 내 시청 시간이 함께 있을 때 툴팁에서 구분해 보여 주도록 정리했습니다.
- 라이브 시청 기록은 이미 정규화된 기록을 재사용하고, 바뀐 내용이 없을 때 불필요한 저장을 피하며, 세션별 저장 범위를 제한하도록 개선했습니다.
- 다시보기 검색은 인덱스 조회 실패를 부분 완료로 저장하지 않고 다음 시도에서 다시 가져오도록 바꿨으며, 댓글/재생 진행률을 임의 문구로 대체하던 fallback을 제거했습니다.
- 통나무 보상 자동 받기는 라이브 채팅 영역 안의 보이는 통나무 보상 버튼만 대상으로 삼고, 비활성/숨김/일반 `받기` 버튼이나 짧은 재렌더링 중복 클릭을 건너뛰도록 했습니다.
- 채팅 도구는 중첩된 채팅 행과 중복 DOM 변경을 한 번만 처리하고, 옵션을 끄면 UI와 수집 동작을 정리하도록 보강했습니다.
- Better Chzzk 컴프레서를 먼저 켠 세션에서는 브라우저 Web Audio 제약 때문에 새로고침 전까지 치즈나이프 컴프레서가 동작하지 않을 수 있습니다. 이 경우 Better Chzzk 그래프는 bypass로 전환해 소리 재생은 유지합니다.
- 컴프레서 그래프 생성이 실패하면 버튼 툴팁에 `사용할 수 없음` 상태를 표시하도록 했습니다.
- 런타임 파일에 원격 실행 코드 패턴이 들어오지 않도록 릴리스 안전 검사를 추가했습니다.
- 광고 차단 안내 팝업 숨김 기능의 옵션과 문서 표현을 더 명확하게 정리했습니다.

### 문서

- README의 기능 목록, 설정 표, 조작 방법, 권한/개인정보 설명을 1.2.0 기능 범위에 맞게 갱신했습니다.
- cheese-knife(MIT) 파생 고지를 `THIRD_PARTY_NOTICES.md`와 컴프레서 런타임 주석에 추가했습니다.
- 기존 기능 문서와 최적화 계획 문서를 현재 동작 기준으로 정리했습니다.

## 1.1.8 (2026-06-28)

### 새 기능

- `팔로잉 호버 미리보기` 옵션을 추가했습니다. 사이드바 팔로잉 라이브에 마우스를 올리면 전체 방송 탐색과 같은 카드 안 미리보기 방식으로 라이브 정보와 썸네일/플레이어 영역을 표시합니다.
- `팔로잉 목록 자동 새로고침`을 보강해 사이드바 팔로잉 채널의 라이브 상태를 설정한 주기마다 안정적으로 갱신합니다.

### 탐색 및 옵션 화면

- 팔로잉 미리보기 옵션을 `탐색` 카테고리로 정리하고, `재생`과 `플레이어` 옵션 카테고리를 하나로 합쳤습니다.
- 팔로잉 미리보기 카드의 LIVE 배지, 시청자 수, 치지직 전용 폰트를 제거해 목록 정보와 중복되는 표시를 줄였습니다.
- 라이브 진행 시간은 `00:00:00` 형식으로 표시하며, 미리보기 정보 영역을 더 타이트하게 정리했습니다.
- 옵션 화면의 헤더와 탭, 상태 표시 스타일을 다듬어 릴리즈 화면 톤을 정리했습니다.

### 수정 및 안정화

- 팔로잉 미리보기는 전체 방송 탐색의 미리보기와 같은 실제 플레이어 기반 경로를 사용하도록 바꿔, 클립이 표시되거나 광고 차단 안내가 먼저 노출되는 문제를 줄였습니다.
- 연속 호버 시 이전 미리보기 요청을 정리하고 새 호버에 필요한 작업만 남겨 과부하를 줄였습니다.
- SPA 경로 전환 감지와 공유 데이터 파싱을 보강하고, 옵션 저장 오류 메시지가 실제 실패 원인을 더 정확히 보여 주도록 정리했습니다.
- 자동 화질 복구가 SPA 이동 뒤에도 필요한 플레이어에 더 안정적으로 적용되도록 감지 범위를 보강했습니다.

- 팔로워 수 배지는 화면 근처 카드 위주로 채워 불필요한 요청을 줄였습니다.
- 설정 탭 이름을 `목록`에서 `탐색`으로 정리했습니다.
- 설정이 변경 즉시 자동 저장되도록 바꾸고 `설정 저장` 버튼을 없앴습니다. 토글은 바로, 숫자 입력은 타이핑이 멎은 뒤 저장됩니다.
- `기본값 복원`을 누르면 실행 전에 확인 창을 띄웁니다. 직접 입력한 수치가 실수로 한 번에 초기화되는 사고를 막습니다.
- 범위를 벗어난 숫자를 입력하면 입력을 마친 시점에 허용 범위로 보정된 값을 입력란에 되돌려 보여줍니다. 이전에는 화면 표시와 다른 값이 조용히 저장됐습니다.

### 수정 및 안정화

- 라이브 지연 시청 중 앞으로 감기(방향키, 시크바 드래그)가 가끔 직전 위치로 되돌아가 연타해야 뚫리던 문제를 수정했습니다. `라이브 위치 유지` 기능이 사용자의 의도적인 전방 이동을 치지직의 강제 실시간 복귀로 오인하던 것이 원인입니다.
- 시크바(타임머신 슬라이더) 조작을 사용자 의도로 인식해 되돌리지 않으며, 시크바를 유예 시간보다 길게 잡고 드래그해도 보호가 유지됩니다. 확장 시크로 실시간 4초 이내에 도달하면 기억해 둔 지연 위치를 정리합니다.
- 볼륨 슬라이더 같은 비시크 조작을 시크바 조작으로 오인하지 않도록 라이브 위치 유지 감지 범위를 좁혔습니다.
- 라이브 `빨리 감기` 버튼을 일시정지 상태에서 눌러도 라이브 끝으로 이동한 뒤 재생을 이어가도록 했습니다.

### 문서

- Whale에서 List-KR 필터를 사용하는 경우 치지직 기본 단축키가 간헐적으로 동작하지 않을 수 있으며, 치지직을 예외 처리하라는 참고 안내를 README에 추가했습니다.

## 1.1.5 (2026-06-10)

### 새 기능

- `볼륨 휠 조절` 옵션을 추가했습니다. 라이브/다시보기 플레이어의 스피커 아이콘이나 볼륨 슬라이더 위에서 마우스 휠을 굴리면 기본 5% 단위로 볼륨을 올리거나 내릴 수 있습니다.
- `볼륨 휠 설정`에서 1틱 볼륨 변화량을 1~50% 사이로 조절할 수 있습니다.
- `긴 제목 툴팁` 옵션을 추가했습니다. 방송/영상 카드의 제목이 말줄임으로 잘릴 때 제목 위에 마우스를 올리면 전체 제목을 툴팁으로 보여줍니다.
- 긴 제목 툴팁은 화면에 보이지 않는 접근성용 텍스트를 제외하고, 실제 제목으로 읽히는 텍스트만 표시합니다.

### 탐색 및 옵션 화면

- 설정 화면의 `라이브/다시보기 조작` 섹션을 정리하고, 볼륨 휠 조절과 긴 제목 툴팁 옵션을 추가했습니다.

### 수정 및 안정화

- 볼륨 휠 조절이 옵션 로드 전에는 동작하지 않도록 했습니다. 옵션에서 기능을 꺼둔 사용자가 페이지 진입 직후 짧은 순간 볼륨 조절을 겪는 문제를 막았습니다.
- 볼륨 휠 조절의 휠 리스너를 라이브/다시보기 재생 경로에서만 붙이도록 정리했습니다.
- 볼륨 휠 조절이 플레이어 영역 밖의 볼륨 유사 컨트롤, 예를 들어 채팅 알림음 설정 같은 UI에서는 휠 이벤트를 가로채지 않도록 범위를 좁혔습니다.
- 자동 화질 복구가 1080p를 찾지 못할 때 선택 가능한 가장 높은 하위 화질로 복구하도록 개선했습니다.
- 다시보기 진입 직후 이어보기/시작 위치 처리와 자동 화질 복구가 충돌하지 않도록, 재생 위치가 안정된 뒤 화질 복구를 시도하게 했습니다.
- 자동 화질 변경 뒤 재생 위치와 재생 상태를 복원하는 로직을 보강했습니다.
- 라이브 `빨리 감기` 버튼이 다른 확장의 유사 버튼과 중복으로 붙지 않도록 감지 범위를 넓혔습니다.
- 라이브 `빨리 감기` 버튼의 아이콘과 라벨/툴팁을 치지직 플레이어 컨트롤에 더 가깝게 정리했습니다.
- 다시보기 채팅 복구 기능을 별도 옵션 없이 항상 동작하도록 바꿨습니다. SPA 이동 뒤 `라이브 채팅 다시보기` 영역이 빠진 VOD만 한 번 새로고침해 복구합니다.
- 다시보기 채팅 복구는 같은 VOD의 `currentTime` 변경만으로는 다시 실행되지 않으며, 확장/넓은 화면 전환이나 레이아웃 재배치 중에는 새로고침을 보류합니다.

### 알려진 이슈

- 일부 환경에서 치지직 네이티브 단축키(스페이스, m, t, f)가 간헐적으로 먹지 않는 문제는 별도 이슈로 유지합니다. 이번 1.1.5 변경과 직접 관련된 수정은 포함하지 않았습니다.
