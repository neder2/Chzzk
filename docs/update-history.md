# 업데이트 내역

## 1.2.5 (2026-07-19)

### 설정 및 표시

- `다시보기에 당시 시간 표시`를 기본으로 켜 장면의 실제 방송 시각을 바로 확인할 수 있도록 했습니다. 기존에 저장한 설정값은 그대로 유지됩니다.
- 채널 방송일 달력 하단에 월 총 방송 시간을 해당 월의 경과 일수 또는 전체 일수로 나눈 일평균 방송 시간을 표시합니다. 조회 상한으로 일부 기록만 반영된 경우에는 `+`와 안내 툴팁으로 구분합니다.
- 환영 메시지 숨기기를 켰을 때 채팅 정리 안내 문구도 함께 숨겨, 빈 여백이나 새로고침 흔적이 남지 않게 했습니다.

### 수정 및 안정화

- 다시보기 댓글의 긴 본문을 펼치거나 접을 때 변경한 댓글 행의 원본 프로필·버프 정보만 다시 동기화해 불필요한 전체 댓글 갱신을 줄였습니다.
- 17시간 분할 다시보기의 이전 세그먼트 상세 요청이 자체 타임아웃 등으로 중단된 경우 이를 전체 작업 취소로 오인하지 않고, 확인한 정보로 방송 시작 시각을 안전하게 추론하도록 보강했습니다.
- 채팅 모아보기 창을 열고 닫을 때 원본 ID가 없는 메시지가 중복으로 쌓이던 문제를 고치고, 실제로 서로 다른 같은 내용의 메시지는 유지했습니다.
- 채팅을 위로 올려 둔 상태에서 발생하던 불필요한 전체 목록 탐색·중복 렌더링·옵저버 되먹임을 줄여 스크롤 성능을 개선했습니다.
- 이미 만들어진 라이브 빨리감기 버튼을 확장이 인식하는 경우에도 클릭 동작이 연결되도록 보완했습니다.

### 검증 및 문서

- 채팅 모아보기의 재마운트·가상 목록·지연 마운트 경로를 회귀 테스트에 추가했습니다.

## 1.2.4 (2026-07-12)

### 다시보기 댓글 탭

- 다시보기 채팅과 댓글 탭을 전환해도 채팅 로그가 콘텐츠 높이만큼 화면을 밀어 플레이어 상하단에 여백이 생기던 문제를 고쳤습니다. 원본 채팅 레이아웃의 절대 위치 규칙을 그대로 유지합니다.
- 댓글 정렬을 원본과 같은 `인기순`(기본)·`최신순`·`등록순` 순서로 맞추고, 댓글 개수와 정렬 도구는 원본 치지직 글꼴을 따라가도록 했습니다.
- 긴 댓글과 답글은 원본에 맞는 접힘 상태로 표시합니다. 답글은 `답글 N` 문구와 화살표 방향을 유지하며, 작은 프로필·좁은 들여쓰기·답글 대상 이름을 함께 표시합니다.
- 하단 원본 댓글의 타임코드 버튼은 표시 시각과 페이지 안 이동 동작을 그대로 사용합니다. 프로필·버프 버튼도 같은 원본 컨트롤만 호출하며, 버프의 초록색 버튼·숫자 피드백은 원본 `aria-pressed` 상태가 켜진 동안에만 동일하게 표시됩니다.

### 설정·재생 안정화

- 설정 화면을 그룹형 레이아웃으로 정리하고, 변경 사항은 `옵션 저장` 버튼을 눌렀을 때 적용하도록 바꿨습니다. 검색 결과에는 필요한 상위 옵션과 의존 옵션을 함께 보여 주고 좁은 화면 탭 이동도 정렬합니다.
- `블라인드 채팅 원문 표시`와 `방송자·채팅 운영자 모아보기`를 독립적으로 켜고 끌 수 있게 했습니다. 이전 채팅 도구 상위 토글은 현재 개별 설정으로 안전하게 이전합니다.
- 통나무 보상 자동 받기의 지연은 실제 동작에 맞는 내부 고정값으로 정리하고, 단축키 복구는 별도 설정 없이 기본 동작으로 제공합니다.
- 17시간 분할 다시보기는 연결된 이전 세그먼트도 확인해 방송 시각과 월간 방송 시간의 종료 구간이 이어지도록 보강했습니다.

### 검증

- 댓글 탭의 채팅 레이아웃·정렬·답글·타임코드·버프 동기화 회귀 테스트를 추가하고 전체 Node 테스트를 통과했습니다.

## 1.2.3 (2026-07-12)

### 새 기능

- 다시보기에서 Space를 잠시 누르고 있으면 누르는 동안 2배속으로 재생하고, 놓으면 기존 배속으로 돌아오는 기능을 추가했습니다.
- 다시보기의 라이브 채팅 다시보기 영역에 `채팅`·`댓글` 탭을 추가했습니다. 댓글·답글과 타임코드를 확인하고 영상을 계속 보면서 해당 시점으로 이동할 수 있으며, 하단 원본 댓글에서 같은 프로필·버프 컨트롤을 확인할 수 있을 때는 해당 동작도 우측에서 사용할 수 있습니다.
- 미리보기 소리를 켰을 때 사용할 고정 볼륨 값을 설정할 수 있도록 했습니다. `/lives` 미리보기를 우클릭해 집중 모드로 보는 동안에는 방송 진행 시간 표시를 숨기고, 확장이 직접 재생하는 미리보기는 가능한 범위에서 화질 제한을 높입니다.

### 수정 및 안정화

- 라이브에서 방송 목록의 미니플레이어로 이동해도 오디오 컴프레서의 연결을 우회 상태로 보존하고, 같은 방송으로 돌아왔을 때 기존 연결을 재사용해 음성이 끊기거나 컴프레서를 다시 켤 수 없던 문제를 막았습니다.
- 라이브 타임머신에서 방향키로 이동하거나 오래 전 시점으로 이동한 뒤 플레이어가 강제로 라이브 시점으로 점프해도, 실제 탐색 가능 범위 안의 마지막 시청 위치로 돌아오도록 보강했습니다. 연속으로 라이브 점프가 발생해도 기존 위치를 잃지 않습니다.
- 라이브의 실제 저장량을 조절하는 기능으로 오해할 수 있었던 `라이브 캐시 용량` 옵션을 삭제했습니다. 보호 범위는 플레이어가 제공하는 실제 탐색 가능 구간을 따릅니다.
- 다시보기 댓글 탭이 하단 댓글 DOM과 페이지 스크롤에 의존하지 않도록 바꿨습니다. VOD 유휴 시간에 첫 10개를 미리 받고 모바일 웹과 같은 `page.next` offset으로 다음 댓글을 이어 붙이며, 로딩·빈 결과·오류·재시도 상태와 정렬별 메모리 캐시를 구분합니다.
- 전체 댓글 래퍼와 직접 댓글 객체 형태의 답글을 함께 표시하고 같은 답글을 중복 제거합니다. 한 댓글의 답글은 50개, 한 정렬 화면에서는 전체 300개까지 렌더하고 초과 사실을 안내합니다. nullable·삭제·클린봇·잘못된 날짜 응답을 안전하게 처리하며, timeout이나 형식을 확인할 수 없는 응답은 빈 결과로 오인하지 않고 다시 시도할 수 있게 했습니다.
- 원래 `라이브 채팅 다시보기`의 문구·높이와 네이티브 채팅 로그를 유지한 채 남은 헤더 공간에 `댓글` 탭을 배치했습니다. 하단 원본에서 측정한 작성자·날짜·본문 글꼴과 치지직 시맨틱 라이트·다크 색상을 따르고, 300px 이하 패널에서는 정렬 도구와 긴 탭 제목이 잘리지 않도록 재배치했습니다.
- 하단 원본 댓글은 이동하거나 복제하지 않고, 같은 댓글의 네이티브 아바타·작성자·버프 컨트롤을 각각 구분해 클릭을 한 번 위임합니다. 원본 댓글 영역만 관찰해 지연된 아바타와 버프의 활성 상태·텍스트 노드 개수·컨트롤 교체를 동기화하고, 원본이 없을 때는 이유 안내와 함께 비활성화합니다. 짧은 aside 교체는 유지하되 영구 제거·SPA 이탈·옵션 해제 때 요청·UI·observer를 정리합니다.
- 정렬·새로고침뿐 아니라 오류 재시도와 다음 댓글 불러오기 뒤에도 대응하는 컨트롤이나 첫 추가 댓글로 키보드 포커스를 복원합니다.
- 통나무 보상 자동 받기가 치지직이 표시한 1시간 시청 인증 버튼과 서버가 제공한 비시청 claim을 함께 처리하도록 보강했습니다. 프로필의 정적 파워 안내는 수령 버튼으로 오인하지 않고, 옵션 해제나 방송 이동 뒤의 오래된 요청은 반영하지 않습니다.
- 다시보기 검색창의 입력 텍스트가 라이트 모드 배경과 같은 색으로 표시되던 문제를 수정했습니다.
- 공용 댓글 요청 경로를 하나로 통합하고, 관찰 대상이 연결된 동안 불필요한 재연결 타이머가 반복 예약되지 않도록 했습니다.
- 설정 화면이 기존 값을 불러오는 동안 입력과 저장을 잠가, 팝업을 연 직후 조작해도 저장해 둔 다른 설정이 기본값으로 덮이지 않도록 했습니다.
- 같은 라이브를 여러 탭에서 동시에 재생한 경우 겹치는 실제 시청 구간을 한 번만 합산하고, 범위로 표현되지 않은 이전 기록의 누적 시간은 그대로 보존하도록 했습니다.
- 방송 정보를 늦게 받더라도 같은 채널의 서로 다른 라이브가 하나의 기록으로 합쳐지지 않게 임시 기록을 세션별로 분리하고, 라이브 ID를 확인하면 기존 기록과 세션을 안전하게 이전하도록 했습니다. 같은 페이지에서 다음 방송으로 전환되거나 영상이 종료되는 경우도 별도 세션으로 마감합니다.
- 개별 삭제 보호 정보와 기록 ID 이전 정보를 제한된 크기로 유지하면서도, 삭제 전에 시작된 늦은 저장 요청이 지운 기록을 되살리지 못하도록 보강했습니다.
- 시청 기록의 다시보기 연결 검색에 상세 요청 수·전체 탐색 시간·연속 오류 상한과 짧은 실패 캐시를 적용해, 후보가 많은 채널에서 과도한 요청을 반복하지 않도록 했습니다.
- 자동 화질이 페이지의 속성 정의 API를 가로채는 동안 비열거·심볼·`__proto__` 속성을 포함한 descriptor의 원래 의미를 보존하도록 수정했습니다.

### 문서

- 재생·미리보기·댓글·보상 개선의 구현 범위와 검증 기준을 계획 문서로 정리하고, README와 개인정보 처리 안내의 기능·조작·데이터 처리 설명을 1.2.3 동작에 맞췄습니다.

## 1.2.2 (2026-07-10)

### 새 기능

- 라이브 방송 목록 필터에 `진행 시간` 조건을 추가했습니다. 방송 시작 후 지난 시간을 구간 버튼이나 직접 입력으로 거를 수 있으며, 현재 목록과 설정한 추가 조회 범위 안에서 동작합니다.
- 채널 월간 달력에서 방송한 날짜를 누르면 그날 첫 방송 다시보기로 이동하고, 날짜 툴팁의 방송 항목을 누르면 해당 다시보기로 바로 이동하도록 했습니다. 보조키나 가운데 클릭으로 새 탭을 열 수도 있습니다.
- 라이브 채팅에 `채팅 시각 표시` 옵션을 추가했습니다. 기본값은 꺼짐이며, 닉네임 왼쪽에 서버 작성 시각을 대괄호 없이 표시합니다. 서버에서 불러온 기존 채팅도 원본 시각을 사용하고, 시각을 확인할 수 없으면 현재 시각을 대신 표시하지 않습니다.

### 탐색 및 옵션 화면

- 진행 시간 필터 버튼 1~6의 기준값을 옵션에서 조절할 수 있도록 했습니다. 기본값은 1·2·4·6·12·24시간입니다.
- 월간 달력의 시청 기록 표시를 `내 시청 표시` 옵션으로 분리했습니다. 기본값은 꺼짐이며, 켰을 때만 시청한 날의 점·툴팁·채널 누적 시청 시간을 표시하고 로컬 시청 기록을 읽습니다.
- 방송 목록 검색·필터 메뉴와 다시보기 검색의 댓글 표시가 치지직 디자인 색상을 따라가도록 정리해 라이트·다크 모드에서 글자와 배경 대비가 자연스럽게 바뀌도록 했습니다.

### 수정 및 안정화

- 진행 시간 필터가 별도 전체 목록을 다시 구성하지 않고 현재 목록과 설정한 추가 조회 범위에서만 동작하도록 해, 긴 목록의 렉과 정렬 영역 UI 충돌을 막았습니다.
- 통나무 보상 자동 받기가 기본 활성화 상태에서도 늦게 나타나는 실제 보상 버튼을 감지하도록 고쳤습니다. 클릭 대기 중 버튼 교체, 동일 버튼의 다음 보상 전환, 다른 방송·다음 주기의 같은 문구와 동시에 표시된 여러 보상을 처리하고, 채팅 영역 전체 재검색 대신 변경된 버튼 후보만 검사하도록 최적화했습니다.
- VOD 방제 이력 패널과 라이브 빨리 감기 버튼이 동일 DOM 값을 반복해서 쓰며 감시자를 다시 깨우지 않도록 했고, 재생 화면에서 SPA로 이탈하면 볼륨 휠 리스너를 즉시 해제하도록 최적화했습니다.
- 고정 공지가 있는 채팅창과 스크롤 래퍼 구조에서도 방송자·채팅 운영자 메시지를 개별 채팅 단위로 모으고, 역할 단어가 포함된 닉네임과 이모티콘 전용 채팅을 잘못 파싱하지 않도록 고쳤습니다.

## 1.2.0 (2026-07-04)

### 새 기능

- `통나무 보상 자동 받기` 옵션을 추가했습니다. 기본값은 켜짐이며, 시청 시간 조작이나 보상 API 직접 호출 없이 치지직 페이지가 실제로 표시한 통나무 보상 버튼만 한 번 클릭합니다.
- `채팅 도구` 옵션을 추가했습니다. 기본값은 꺼짐이며, 확인할 수 있는 블라인드 채팅 원문만 보여 주고 방송자/매니저 채팅을 채팅창 우측 상단 아이콘에서 여는 패널에 모아 보여 줍니다. `방송 중 모아보기 유지`를 켜면 보고 있는 동안 모은 방송자/매니저 채팅만 같은 방송 재입장 때 다시 보여 줍니다.
- `오디오 컴프레서` 옵션을 추가했습니다. 기본값은 꺼짐이며, 옵션을 켜면 라이브/다시보기 볼륨 컨트롤에 치즈나이프식 컴프레서 버튼을 표시하고 옵션을 끄면 버튼을 제거합니다. 치즈나이프 컴프레서가 감지되면 오디오 소스 충돌을 피하기 위해 Better Chzzk 컴프레서 버튼을 자동으로 숨기고, 치즈나이프가 없으면 기존대로 동작합니다.
- `팔로잉 미리보기 소리` 옵션을 추가했습니다. 기본값은 켜짐이며, 주 플레이어 볼륨으로 미리보기 소리 재생을 시도하고 브라우저가 소리 자동재생을 막으면 카드 안 버튼으로 소리를 켤 수 있습니다.

### 탐색 및 옵션 화면

- 옵션 화면에 통나무 보상, 오디오 컴프레서, 채팅 도구, 팔로잉 미리보기 소리 설정을 추가하고 상위 토글 상태에 따라 세부 입력이 함께 비활성화되도록 정리했습니다.
- 채팅 도구 설정을 별도 섹션으로 분리하고, 방송자/매니저 모아보기 캐시와 보관 개수 설정을 한곳에서 조절할 수 있게 했습니다.
- 전체 방송/카테고리 목록 도구는 검색, 필터, 팔로워 수 배지, 진행 시간 배지를 큰 목록에서도 덜 무겁게 갱신하도록 화면 근처 카드와 주기적 동기화 중심으로 정리했습니다.
- 팔로잉 미리보기 카드는 라이브 썸네일을 우선 사용하고, 썸네일이 없을 때 `LIVE` 같은 장식용 대체 화면을 만들지 않도록 정리했습니다.

### 수정 및 안정화

- 팔로잉 미리보기는 기존 MAIN world 영상 브리지를 제거하고, 전체 방송 탐색 hover와 같은 `auto-play-info` HLS 정보를 받아 카드 안에서 재생하도록 다시 만들었습니다. 기본적으로 주 플레이어 볼륨으로 소리 재생을 시도하고, 브라우저가 자동재생을 막으면 음소거로 전환한 뒤 카드 안 버튼으로 소리를 켤 수 있습니다.
- 팔로잉 미리보기에서 CHZZK `player-vendor` 원격 import, 새 창, 새 탭, 팝업, iframe, 라이브 페이지 삽입 fallback을 사용하지 않도록 정리했습니다.
- 팔로잉 미리보기 카드 자체는 즉시 열되, 메타데이터 조회와 플레이어 시작은 짧게 지연해 지나가는 호버에서 불필요한 요청이 생기는 일을 줄였습니다.
- 팔로잉 미리보기 플레이어를 메인 라이브 플레이어로 오인하지 않도록 공용 비디오 선택 로직을 보강했습니다.
- 자동 화질 복구가 다시보기 진입 직후의 안정된 상태를 더 정확히 판단하고, 이미 원하는 화질이 적용된 경우 불필요한 재적용과 리스너를 정리하도록 개선했습니다.
- 라이브 위치 유지가 시크바 드래그, 명시적인 라이브 끝 이동, 일시정지 후 이어보기, 비디오 교체 상황을 더 구분해 사용자가 의도한 위치를 되돌리지 않도록 보강했습니다.
- 17시간 단위로 분할된 다시보기에서 방송 시각 표시가 원본 방송 시작 기준으로 앞당겨지던 문제를 보정했습니다.
- 월간 방송 달력은 KST 날짜 경계를 기준으로 방송일을 칠하고, 같은 날짜에 방송 시간과 내 시청 시간이 함께 있을 때 툴팁에서 구분해 보여 주도록 정리했습니다.
- 라이브 시청 기록은 이미 정규화된 기록을 재사용하고, 바뀐 내용이 없을 때 불필요한 저장을 피하며, 세션별 저장 범위를 제한하도록 개선했습니다.
- 다시보기 검색은 인덱스 조회 실패를 부분 완료로 저장하지 않고 다음 시도에서 다시 가져오도록 바꿨으며, 댓글/재생 진행률을 임의 문구로 대체하던 fallback을 제거했습니다.
- 통나무 보상 자동 받기는 라이브 채팅 영역 안의 보이는 통나무 보상 버튼만 대상으로 삼고, 비활성/숨김/일반 `받기` 버튼이나 짧은 재렌더링 중복 클릭을 건너뛰도록 했습니다.
- 채팅 도구는 중첩된 채팅 행과 중복 DOM 변경을 한 번만 처리하고, 옵션을 끄면 UI와 수집 동작을 정리하도록 보강했습니다.
- Better Chzzk 컴프레서를 먼저 켠 세션에서는 브라우저 Web Audio 제약 때문에 새로고침 전까지 치즈나이프 컴프레서가 동작하지 않을 수 있습니다. 이 경우 Better Chzzk 그래프는 bypass로 전환해 소리 재생은 유지합니다.

- 라이브 진행 시간은 `00:00:00` 형식으로 표시하며, 미리보기 정보 영역을 더 타이트하게 정리했습니다.
- 옵션 화면의 헤더와 탭, 상태 표시 스타일을 다듬어 릴리즈 화면 톤을 정리했습니다.

### 수정 및 안정화

- 팔로잉 미리보기는 전체 방송 탐색의 미리보기와 같은 실제 플레이어 기반 경로를 사용하도록 바꿔, 클립이 표시되거나 광고 차단 안내가 먼저 노출되는 문제를 줄였습니다.
- 연속 호버 시 이전 미리보기 요청을 정리하고 새 호버에 필요한 작업만 남겨 과부하를 줄였습니다.
- SPA 경로 전환 감지와 공유 데이터 파싱을 보강하고, 옵션 저장 오류 메시지가 실제 실패 원인을 더 정확히 보여 주도록 정리했습니다.
- 자동 화질 복구가 SPA 이동 뒤에도 필요한 플레이어에 더 안정적으로 적용되도록 감지 범위를 보강했습니다.

### 새 기능

- `팔로잉 목록 자동 새로고침` 옵션을 추가했습니다. 사이드바 팔로잉 채널의 라이브 상태를 설정한 주기마다 갱신합니다.
- 일시정지 중 `,` / `.` 키로 프레임 단위 이동을 할 수 있도록 했습니다.
- `볼륨 툴팁` 옵션을 추가했습니다. 볼륨 바에 마우스를 올리면 현재 볼륨을 %로 보여줍니다. 기본값은 꺼짐입니다.

### 탐색 및 옵션 화면

- 전체 방송 목록 검색창을 카테고리 페이지와 같은 탭 라인 쪽에 배치했습니다.
- 전체 방송 목록의 기본 태그 검색창을 숨기고 확장 검색/필터만 표시하는 옵션을 정리했습니다.
- 검색/필터용 메타데이터를 스크롤 흐름에 맞춰 점진적으로 불러오도록 개선했습니다.
- 팔로워 수 배지는 화면 근처 카드 위주로 채워 불필요한 요청을 줄였습니다.
- 설정 탭 이름을 `목록`에서 `탐색`으로 정리했습니다.
- 설정이 변경 즉시 자동 저장되도록 바꾸고 `설정 저장` 버튼을 없앴습니다. 토글은 바로, 숫자 입력은 타이핑이 멎은 뒤 저장됩니다.
- `기본값 복원`을 누르면 실행 전에 확인 창을 띄웁니다. 직접 입력한 수치가 실수로 한 번에 초기화되는 사고를 막습니다.
- 범위를 벗어난 숫자를 입력하면 입력을 마친 시점에 허용 범위로 보정된 값을 입력란에 되돌려 보여줍니다. 이전에는 화면 표시와 다른 값이 조용히 저장됐습니다.

### 수정 및 안정화

- 라이브 지연 시청 중 앞으로 감기(방향키, 시크바 드래그)가 가끔 직전 위치로 되돌아가 연타해야 뚫리던 문제를 수정했습니다. `라이브 위치 유지` 기능이 사용자의 의도적인 전방 이동을 치지직의 강제 실시간 복귀로 오인하던 것이 원인입니다.
- 시크바(타임머신 슬라이더) 조작을 사용자 의도로 인식해 되돌리지 않으며, 시크바를 유예 시간보다 길게 잡고 드래그해도 보호가 유지됩니다. 확장 시크로 실시간 4초 이내에 도달하면 기억해 둔 지연 위치를 정리합니다.
- 볼륨 슬라이더 같은 비시크 조작을 시크바 조작으로 오인하지 않도록 라이브 위치 유지 감지 범위를 좁혔습니다.
- 라이브 `빨리 감기` 버튼을 일시정지 상태에서 눌러도 라이브 끝으로 이동한 뒤 재생을 이어가도록 했습니다.

### 문서

- Whale에서 List-KR 필터를 사용하는 경우 치지직 기본 단축키가 간헐적으로 동작하지 않을 수 있으며, 치지직을 예외 처리하라는 참고 안내를 README에 추가했습니다.

## 1.1.5 (2026-06-10)

### 새 기능

- `볼륨 휠 조절` 옵션을 추가했습니다. 라이브/다시보기 플레이어의 스피커 아이콘이나 볼륨 슬라이더 위에서 마우스 휠을 굴리면 기본 5% 단위로 볼륨을 올리거나 내릴 수 있습니다.
- `볼륨 휠 설정`에서 1틱 볼륨 변화량을 1~50% 사이로 조절할 수 있습니다.
- `긴 제목 툴팁` 옵션을 추가했습니다. 방송/영상 카드의 제목이 말줄임으로 잘릴 때 제목 위에 마우스를 올리면 전체 제목을 툴팁으로 보여줍니다.
- 긴 제목 툴팁은 화면에 보이지 않는 접근성용 텍스트를 제외하고, 실제 제목으로 읽히는 텍스트만 표시합니다.

### 탐색 및 옵션 화면

- 설정 화면의 `라이브/다시보기 조작` 섹션을 정리하고, 볼륨 휠 조절과 긴 제목 툴팁 옵션을 추가했습니다.

### 수정 및 안정화

- 볼륨 휠 조절이 옵션 로드 전에는 동작하지 않도록 했습니다. 옵션에서 기능을 꺼둔 사용자가 페이지 진입 직후 짧은 순간 볼륨 조절을 겪는 문제를 막았습니다.
- 볼륨 휠 조절의 휠 리스너를 라이브/다시보기 재생 경로에서만 붙이도록 정리했습니다.
- 볼륨 휠 조절이 플레이어 영역 밖의 볼륨 유사 컨트롤, 예를 들어 채팅 알림음 설정 같은 UI에서는 휠 이벤트를 가로채지 않도록 범위를 좁혔습니다.
- 자동 화질 복구가 1080p를 찾지 못할 때 선택 가능한 가장 높은 하위 화질로 복구하도록 개선했습니다.
- 다시보기 진입 직후 이어보기/시작 위치 처리와 자동 화질 복구가 충돌하지 않도록, 재생 위치가 안정된 뒤 화질 복구를 시도하게 했습니다.
- 자동 화질 변경 뒤 재생 위치와 재생 상태를 복원하는 로직을 보강했습니다.
- 라이브 `빨리 감기` 버튼이 다른 확장의 유사 버튼과 중복으로 붙지 않도록 감지 범위를 넓혔습니다.
- 라이브 `빨리 감기` 버튼의 아이콘과 라벨/툴팁을 치지직 플레이어 컨트롤에 더 가깝게 정리했습니다.
- 다시보기 채팅 복구 기능을 별도 옵션 없이 항상 동작하도록 바꿨습니다. SPA 이동 뒤 `라이브 채팅 다시보기` 영역이 빠진 VOD만 한 번 새로고침해 복구합니다.
- 다시보기 채팅 복구는 같은 VOD의 `currentTime` 변경만으로는 다시 실행되지 않으며, 확장/넓은 화면 전환이나 레이아웃 재배치 중에는 새로고침을 보류합니다.

### 알려진 이슈

- 일부 환경에서 치지직 네이티브 단축키(스페이스, m, t, f)가 간헐적으로 먹지 않는 문제는 별도 이슈로 유지합니다. 이번 1.1.5 변경과 직접 관련된 수정은 포함하지 않았습니다.
