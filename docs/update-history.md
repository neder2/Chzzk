# 업데이트 내역

## 미출시

## 1.1.5 (2026-06-10)

- 라이브/다시보기 플레이어의 볼륨 조절 영역 위에서 마우스 휠로 볼륨을 조절할 수 있는 `볼륨 휠 조절` 옵션을 추가했습니다.
- 잘려 보이는 방송/영상 제목에 마우스를 올리면 전체 제목을 확인할 수 있는 `긴 제목 툴팁` 옵션을 추가했습니다.
- 볼륨 휠 조절이 설정 로드 전에는 동작하지 않도록 하고, 플레이어 영역 밖의 볼륨 유사 컨트롤에서는 휠 이벤트를 가로채지 않도록 범위를 좁혔습니다.

## 1.1.4 (2026-06-02)

- 라이브 위치 유지가 기억하는 범위를 옵션에서 `라이브 캐시 용량`(분)으로 조절할 수 있도록 했습니다. 실시간 끝에서 설정한 시간 이내로 떨어진 위치만 기억해 되돌리고, 위치 값이 어떻게 저장되는지 설명하는 툴팁을 함께 추가했습니다.
- 라이브 타임머신 시청 중 플레이어가 실시간 위치로 강제 복귀하는 동작을 감지해 기존 위치로 되돌리는 보호 로직을 추가했습니다.
- 라이브 플레이어 컨트롤에 `빨리 감기` 버튼을 추가했습니다. 버튼은 현재 버퍼의 라이브 끝 지점으로 이동하며, cheese-knife와 같은 라벨/툴팁/다음 미디어 아이콘 형태를 사용합니다.
- 다시보기 방송시각 표시 기능을 기본 비활성화로 변경하고, 방송 시작 시각을 확인할 수 없는 VOD에서는 표시가 남지 않도록 정리했습니다.
- 월간 달력 누적 시간 라벨을 `내 시청 시간`으로 정리했습니다.
