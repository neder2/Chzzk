치지직 자동 화질, 다시보기 스킵/검색, 방송 목록 필터, 채널 방송 시간, 안내 팝업 정리를 기능별로 조절합니다.

불러오는 중

재생 기본값

라이브와 다시보기 플레이어 화질을 1080p로 자동 복구합니다.

새로고침 설정

설정한 주기마다 팔로잉 목록을 갱신합니다. 주기를 줄이면 라이브 시작이 더 빨리 반영됩니다.

시청 기록

라이브 재생 시간을 이 브라우저에 저장하고, 월별 달력과 라이브별 누적 시간을 확인합니다.

시청 기록 설정

설정한 시간보다 짧게 본 라이브는 시청 기록에 저장하지 않습니다.

시청 기록 보기

기록은 Chrome 동기화가 아닌 이 브라우저의 로컬 저장소에만 저장됩니다.

라이브/다시보기 조작

라이브 위치 유지, 방향키 이동, 플레이어 버튼, 다시보기 보조 기능을 조절합니다.

라이브 위치 유지 설정

‘라이브 위치 유지’가 켜져 있을 때만 적용됩니다. 실시간에서 설정한 시간보다 더 뒤로 가면 위치를 기억하지 않고 치지직 기본 동작을 따릅니다.

스킵 수치 설정
볼륨 휠 설정

볼륨 조절 영역(스피커 아이콘/슬라이더) 위에서 휠을 굴릴 때 적용됩니다.

안내 팝업

시청 중 뜨는 광고 차단 관련 안내 팝업을 정리합니다.

채널 방송 시간

다시보기의 방송 시작/종료 시간을 기준으로 최근 평균과 월별 방송일을 표시합니다.

방송 시간 수치 설정

달력은 읽은 페이지를 잠시 캐시하며, 조회 상한을 낮출수록 채널 페이지 반응이 빨라집니다.

다시보기 검색

채널 다시보기 탭에서 제목 검색을 보강하고, 필요하면 댓글 일부까지 확인합니다.

검색 수치 설정

댓글 검색은 요청량이 커서 지연값과 영상 수를 낮출수록 페이지 반응이 빨라집니다.

방송 목록 필터

전체 방송과 카테고리 목록의 검색, 시청자/팔로워 필터, 배지를 조절합니다.

필터 버튼 기준값

각 필터의 1번 값은 “이하” 버튼 기준이고, 이후 값은 구간 버튼의 경계값으로 사용됩니다.

목록 조회 수치 설정

추가 조회 페이지를 낮추면 목록 필터 반응이 빨라지고, 높이면 더 멀리 있는 방송까지 필터링합니다.

설정이 저장되었습니다.
