Better Chzzk는 치지직(CHZZK) 시청과 탐색을 더 편하게 만들어 주는 비공식 Chrome 확장 프로그램입니다. 자동 화질과 재생 조작부터 채팅 모아보기, 팔로잉 관리, 다시보기 검색과 시청 기록까지 필요한 기능을 한곳에 모았습니다. 대부분의 기능을 설정에서 개별로 켜고 끌 수 있습니다.

[플레이어와 시청 편의]
• 라이브 멀티뷰: 최대 6개 방송을 함께 보고 배치, 자리별 소리와 채널별 싱크를 조절할 수 있습니다.
• LIVE 배지 숨김, 방송 시작 시간 표시와 오프라인 방송 자동 새로고침을 지원합니다.
• 자동 화질 복구: 설정한 목표 화질(1080p·720p·480p)을 우선 적용하고, 없으면 가능한 하위 화질을 선택합니다.
• 그리드 우회: 지원되는 라이브 재생 정보의 공식 직접 HLS 경로를 사용합니다.
• 다시보기·타임머신 앞뒤 스킵, 스킵 시간 조절, 일시정지 중 실시간 복귀 방지, 라이브 끝 지점으로 이동을 지원합니다.
• Space를 길게 누르는 동안 2배속으로 재생하며, [ / ] 키로 0.5배속·2배속을 고정하거나 해제할 수 있습니다. 배속 키는 변경할 수 있습니다.
• 볼륨 휠 조절, 볼륨 표시, 오디오 컴프레서와 기본 재생 단축키 복구를 제공합니다.
• 다시보기 장면의 실제 방송 시각과 타임머신의 실시간 대비 지연 시간을 표시합니다.

[채팅과 다시보기 댓글]
• 채널 채팅 링크를 제공합니다.
• 방송자·채팅 운영자 모아보기: 사용자별 필터, 미확인 채팅 개수, 맨 아래로 이동, 여러 채팅 선택·복사를 지원합니다. 패널에서 실제로 화면에 보인 채팅만 확인 처리합니다.
• 라이브 채팅의 실제 서버 작성 시각을 표시하고, 환영·필터링 안내 메시지를 숨길 수 있습니다.
• 블라인드 채팅은 페이지에서 확인할 수 있는 원문만 표시합니다. 원문이 없으면 기존 안내를 유지합니다.
• 다시보기 우측 패널에서 댓글·답글·타임코드를 확인할 수 있습니다. 라이브 채팅 다시보기가 없는 영상에도 댓글 패널을 제공합니다.
• 페이지 내부 이동 후 누락된 다시보기 채팅을 복구하는 보조 기능을 제공합니다.

[팔로잉과 방송 탐색]
• 팔로잉 채널 고정과 오프라인 채널 최상단 고정, 사이드바 치즈팜·인기 카테고리·다가오는 방송 일정·파트너 스트리머·서비스 바로가기 숨김을 지원합니다.
• 접힌 목록 밖의 고정 채널을 보충하고, 선택한 채널로 페이지 내부에서 이동합니다.
• 팔로잉 목록 자동 새로고침과 현재 라이브의 제목 변경 이력을 제공합니다.
• 팔로잉·방송 목록에서 라이브를 미리 볼 수 있으며, 소리와 볼륨을 조절할 수 있습니다. 전체 방송 목록 미리보기는 우클릭으로 확대할 수 있습니다.
• 라이브·영상·클립 목록 검색, 팔로워·시청자·조회수·진행 시간 필터, 팔로워 수 표시와 긴 제목 툴팁을 제공합니다.
• 채널 다시보기를 제목과 댓글 내용으로 검색할 수 있습니다.

[방송 통계와 기록]
• 채널별 평균 방송 시간과 월간 방송 달력을 제공합니다.
• 라이브 시청 시간을 이 브라우저에 기록하고, 전용 시청 기록 페이지에서 목록·달력·통계를 확인할 수 있습니다.
• 통나무 보상 자동 받기와 광고 차단 안내 팝업 숨김을 제공합니다.

[기본 설정과 이용 안내]
• 설정의 팝업·알림 → 업데이트 알림 → 튜토리얼 다시보기에서 열린 치지직 탭의 안내를 처음부터 다시 볼 수 있습니다. 알림 설정과 확인 기록은 유지합니다.
• 업데이트 시 치지직 상단 알림과 확장 아이콘의 NEW 배지로 안내합니다. 열린 치지직 탭에 패키지 내부 알림을 표시하기 위해 scripting 권한과 치지직 호스트 권한을 사용하며, 설정에서 업데이트 알림을 끌 수 있습니다.
• 통나무 보상 자동 받기는 기본으로 켜져 있습니다. 1시간 시청 보상은 치지직이 표시한 수령 버튼으로 받고, 그 외 대기 중인 보상은 치지직이 제공한 claim 목록과 보상 API로 처리합니다. 시청 시간을 조작하지 않습니다.
• 채팅 타임스탬프, 환영 메시지 제거, 블라인드 원문 표시, 방송자·운영자 모아보기, 볼륨 표시, 컴프레서 버튼, 라이브 멀티뷰, 라이브 호버 미리보기는 기본으로 꺼져 있습니다.
• 라이브 멀티뷰 또는 라이브 호버 미리보기를 켤 때 영상 제공 호스트(pstatic.net)의 추가 접근 권한을 요청합니다. 미리보기 소리 설정은 켜짐, 볼륨은 15%가 기본이며 브라우저의 자동재생 제한에 따라 음소거로 시작할 수 있습니다.
• 스킵 시간, 배속 키, 볼륨 조절 단위, 검색 범위, 필터 기준, 새로고침 주기, 채팅 보관 개수 등을 조정할 수 있습니다.

[데이터와 개인정보]
멀티뷰 배치·크기·박스 안 영상 위치와 자리별 소리는 탭 세션에 보관되며 치지직 페이지 스크립트에서도 읽을 수 있습니다. 채널별 목표 딜레이는 확장 로컬 저장소에 보관해 다음 방송에도 불러옵니다. 업데이트 버전과 안내 확인 상태는 이 기기의 로컬 저장소에 보관됩니다.
설정과 고정 채널 목록은 Chrome 동기화 저장소에 보관됩니다. 시청 기록, 팔로잉 라이브 제목 이력, 컴프레서의 마지막 선택과 댓글 요청용 임의 식별자는 이 기기의 로컬 저장소에 보관됩니다. 댓글 요청용 식별자는 댓글을 불러올 때 네이버 댓글 API에 전달합니다. 이 데이터를 개발자 서버로 전송하지 않습니다.

모아 둔 채팅과 사용자 목록, 미확인 상태는 현재 페이지 메모리에서만 유지하며 브라우저 저장소에 저장하지 않습니다. 새로고침하거나 다른 방송으로 이동하면 초기화됩니다.

Better Chzzk는 NAVER 또는 치지직과 제휴하거나 공식적으로 운영되는 프로그램이 아닙니다. 치지직의 화면 구성이나 API 변경에 따라 일부 기능이 동작하지 않을 수 있습니다.
